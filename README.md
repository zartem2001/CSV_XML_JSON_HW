# CSV/XML → JSON парсер

## 📋 Описание задачи

Написать конвертеры из форматов **CSV** и **XML** в **JSON** на Java, 
используя вспомогательные библиотеки: `opencsv`, `json-simple`, `gson`.

Проект состоит из двух задач:
1. **Задача 1:** Парсинг CSV → список объектов → JSON.
2. **Задача 2:** Парсинг XML → список объектов → JSON.

Обе задачи выполняются в одном проекте (Gradle или Maven).

## 🎯 Цель

Отработать практическое применение:
- Парсинга CSV через библиотеку **opencsv**;
- Парсинга XML через **DOM-парсер** (`DocumentBuilderFactory`);
- Сериализации объектов в JSON через **Gson**;
- Работы с файлами через `FileReader` / `FileWriter`.

## 🛠️ Используемые технологии

- Java 17+
- Gradle (или Maven)
- **opencsv** 5.1 — парсинг CSV
- **json-simple** 1.1.1 — работа с JSON
- **gson** 2.8.2 — сериализация объектов в JSON
- DOM-парсер (`javax.xml.parsers`) — парсинг XML
- `FileReader` / `FileWriter`
